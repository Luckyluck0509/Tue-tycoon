  <h1>TUe Tycoon</h1>
  <h2>Description</h2>
  
  <p>TU/e Tycoon is an incremental university simulator inspired by the Computer Science & Engineering program at TU Eindhoven.
  
  Start your journey as a first-year student and earn ECTS by studying, attending lectures, and completing courses. As your progress grows, you can rebirth to advance to the next             quartile, unlocking new challenges and opportunities while keeping permanent bonuses.
  
  Your ultimate goal is to earn 60 ECTS within 4 quartiles and secure a positive Binding Study Advice (BSA). Manage your time wisely, optimize your study strategy, and see how efficiently    you can progress through the academic year.
  
  Can you survive the TU/e grind and make it to the end of the year?</p>

  <h2>How to run the .jar file</h2>
  <ol>
    <li>Have a version of JDK of 25 or newer installed</li>
    <li>Download the project as a .zip archive</li>
    <li>Unzip the archive using your favourite tool</li>
    <li>Run the .jar file in the unzipped folder</li>
  </ol>

  <h2>How to run the executable</h2>
  <h3>Windows</h3>
  <ol>
    <li>Download the zip archive</li>
    <li>Extract the zip using your favourite tool</li>
    <li>Locate the exe file in the folder and run it</li>
  </ol>

  <p>PS: If you want to cheat, run the game, save your progress and then a save.txt file should appear in the game folder. Edit the values in the txt file to cheat</p>
